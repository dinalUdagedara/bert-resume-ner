# Fix: Remove Large Model File from Git

The model file (415MB) exceeds GitHub's 100MB limit. Here's how to fix it:

## Option 1: Remove model file from git (Recommended)

**Step 1: Remove the file from git tracking (but keep it locally)**
```bash
git rm --cached model-state.bin
```

**Step 2: Update .gitignore (already done)**
The `.gitignore` file now includes `model-state.bin`

**Step 3: Amend your commit**
```bash
git add .gitignore
git commit --amend --no-edit
```

**Step 4: Force push (since you're rewriting history)**
```bash
git push -u origin main --force
```

## Option 2: Use Git LFS (if you want to track the model)

If you really want to track the model file in git:

**Step 1: Install Git LFS**
```bash
brew install git-lfs  # macOS
# or download from https://git-lfs.github.com
```

**Step 2: Initialize Git LFS**
```bash
git lfs install
```

**Step 3: Track .bin files with LFS**
```bash
git lfs track "*.bin"
git add .gitattributes
git commit --amend --no-edit
```

**Step 4: Push**
```bash
git push -u origin main --force
```

## Recommendation

**Use Option 1** - It's simpler and the model file can be regenerated by running `python3 train.py`. 
You can add a note in your README that users need to train the model or download it separately.
